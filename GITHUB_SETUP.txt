GITHUB पर UPLOAD कैसे करें - STEP BY STEP
═══════════════════════════════════════════════════════════════════════════════════

अगर phone से GitHub use कर रहे हो:

═════════════════════════════════════════════════════════════════════════════════

OPTION 1: GitHub Web से (सबसे आसान) 📱

══════════════════════════════════════════════════════════════════════════════════

Step 1: New Repository बनाओ
────────────────────────────
1. GitHub.com खोलो
2. Sign in करो अपने account से
3. Top right में '+' icon दबाओ
4. "New repository" चुनो
5. Repository का नाम दो (e.g., "Vision-v4")
6. "Create repository" दबाओ

Step 2: Files Upload करो
────────────────────────
1. नई repository खुली होगी
2. "Add file" button दबाओ
3. "Upload files" चुनो
4. यह extracted Vision folder को select करो
5. सभी files आ जाएंगी
6. "Commit changes" दबाओ

Step 3: GitHub Actions होगा काम
──────────────────────────────
1. Repository में .github/workflows/build.yml है
2. यह automatically काम करेगा
3. "Actions" tab में देख सकते हो
4. 5-10 minutes में APK ready हो जाएगा

Step 4: APK Download करो
────────────────────────
1. Repository में "Actions" tab जाओ
2. सबसे ऊपर की build को click करो
3. नीचे scroll करो "Artifacts" section में
4. "Vision-APK" को download करो
5. यह तुम्हारा APK है!

═════════════════════════════════════════════════════════════════════════════════

OPTION 2: GitHub Desktop (अगर PC है)
════════════════════════════════════

1. GitHub Desktop install करो
2. Sign in करो GitHub से
3. "Create a New Repository" दबाओ
4. Repository का नाम दो
5. Local Path चुनो (जहाँ यह folder है)
6. "Create Repository" दबाओ
7. "Publish repository" दबाओ
8. "Publish" दबाओ

फिर:
1. GitHub Desktop में repository खुली होगी
2. "Add" button दबाओ
3. यह Vision folder को add करो
4. "Commit to main" दबाओ
5. "Push origin" दबाओ

GitHub Actions automatically शुरू हो जाएगा!

═════════════════════════════════════════════════════════════════════════════════

OPTION 3: Command Line (अगर terminal आता है)
═══════════════════════════════════════════

```bash
# Repository folder में जाओ
cd Vision-FINAL-ALL-VERSIONS

# Git initialize करो
git init

# सभी files add करो
git add .

# Commit करो
git commit -m "Vision v4.0 - Complete autonomous AI assistant"

# Branch का नाम change करो
git branch -M main

# Remote add करो (GitHub पर अपनी repository का link)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# Push करो
git push -u origin main
```
