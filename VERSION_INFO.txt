🚀 HOW TO USE:

OPTION 1: Direct GitHub Push (सबसे आसान)
──────────────────────────────────────────

1. Extract यह ZIP file
2. GitHub पर नई repository बनाओ (कोई भी नाम दे सकते हो)
3. इस extracted folder को GitHub में upload करो
4. GitHub Actions automatically करेगा:
   - Build the project
   - Generate APK
   - Make it available for download

OPTION 2: Local Build (अगर Android Studio है)
────────────────────────────────────

1. Extract यह ZIP
2. Android Studio में open करो
3. Build → Build APK
4. APK पाओ app/build/outputs/apk/release/

OPTION 3: Command Line
──────────────────────

./gradlew build
./gradlew assembleRelease
